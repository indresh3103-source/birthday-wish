# Birthday Wish Cinematic Frontend

A frontend-only immersive romantic birthday surprise built with React, Next.js, Tailwind CSS, Three.js, GSAP, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Personalize

- Replace the gallery placeholders in `src/lib/content.ts` with real captions or connect them to local images.
- Update the relationship start date in `src/app/page.tsx` inside `LoveCounter`.
- Customize the headline and secret messages directly in `src/app/page.tsx`.
